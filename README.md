# SDL3 GUI

Attempting to create a GUI with SDL3

![Screenshot of my app](images/screenshot.png)

## Prerequisites

- [CMake](https://cmake.org/download/) (3.15+)
- [Visual Studio 2022](https://visualstudio.microsoft.com/downloads/) with "Desktop development with C++" workload
- [vcpkg](https://github.com/microsoft/vcpkg) (only needed for first-time setup)

---

## Quick Setup

Run `create_project.bat` from your terminal in the project root:

```bat
create_project.bat
```

That's it. It will:
1. Install dependencies via vcpkg
2. Move them into `Dependencies/`
3. Reconfigure the project to use the local folder
4. Rewrite `.vcxproj` paths to use `$(SolutionDir)`

Then open the solution in Visual Studio and build.

---

## Manual Setup

### Step 1: Configure with vcpkg (installs dependencies)

```bash
cmake -B build -S . -DCMAKE_TOOLCHAIN_FILE=C:/vcpkg/scripts/buildsystems/vcpkg.cmake
```

CMake reads your `vcpkg.json`, vcpkg installs all packages into `build/vcpkg_installed/x64-windows/`.

> Replace `C:/vcpkg` with your local vcpkg path (run `vcpkg root` to find it).

### Step 2: Move the dependencies out of `build/`

```bat
rmdir /S /Q Dependencies
move build\vcpkg_installed Dependencies
```

This moves the folder to a top-level `Dependencies/` so it survives clean builds and can be shared.

### Step 3: Reconfigure without vcpkg

```bat
del build\CMakeCache.txt
cmake -B build -S .
```

The first configure baked vcpkg paths into the cache. Deleting it and reconfiguring without the toolchain file makes CMake use the `CMAKE_PREFIX_PATH` in `CMakeLists.txt`, which points at `Dependencies/x64-windows/`. The generated `.vcxproj` files now reference `Dependencies/` instead of the old `build/vcpkg_installed/` location.

### Step 4: Build

```bat
cmake --build build --config Release
```

Or open the solution in Visual Studio and hit **Ctrl+Shift+B**.

---

## Building (after setup)

No vcpkg required:

```bat
cmake -B build -S .
cmake --build build
```

---

## Updating Dependencies

1. Delete `Dependencies/`
2. Delete `build/`
3. Re-run `create_project.bat` (or repeat the manual steps)
